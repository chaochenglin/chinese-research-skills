# 中文科研写作与汇报 Skills

把科研工作讲清楚：研究什么，为什么这样做，每一步怎样衔接，最终选择什么，数据说明什么。

本仓库由 [Chao（@chaochenglin）](https://github.com/chaochenglin) 根据实际科研写作、成果汇报和人工修改经验整理，并借助 AI 辅助迭代。提供两个可分别使用的技能：

| 技能 | 适合的任务 | 入口 |
|---|---|---|
| 中文ZH · 科研汇报PPT制作 | 研究进展、方法、结果及工程评估的口头汇报 | [research-briefing-ppt](skills/research-briefing-ppt/SKILL.md) |
| 中文科研报告写作 | 中文方法章节、科研读图、定量结果和完整研究报告 | [scientific-chinese-explanation](skills/scientific-chinese-explanation/SKILL.md) |

## 写作原则

- 名词第一次出现时，解释它对应的具体对象、动作和用途。
- 沿研究问题组织方法、比较、选择和结果，讲清步骤之间的关系。
- 文字可以详细，但每段都应增加解释；图表应支撑判断。
- 用有对象、单位和比较关系的数字说明结果，保留真实的相反变化。
- 正文集中呈现研究认识，减少重复自证、工程黑话和后台操作记录。
- PPT在每页组织一个要回答的问题；报告用连续段落完整展开推理。

## 安装与使用

两个技能均以标准 `SKILL.md` 为入口，`agents/openai.yaml` 提供可选的界面名称和示例提示。选择其中一个或两个目录，放入所用代理支持的技能目录即可。请保留技能目录内的 `references/` 文件。

例如，在使用用户级 `~/.codex/skills/` 目录的环境中，将以下目录分别复制进去：

```text
skills/research-briefing-ppt/
skills/scientific-chinese-explanation/
```

示例请求：

```text
使用 $research-briefing-ppt，根据这份研究材料制作15分钟的中文汇报。
先讲研究目的，再说明方法选择，最后用图表解释结果。按我提供的模板排版。

使用 $scientific-chinese-explanation，把这一章改写成连续的中文科研叙述。
讲清每一步为什么需要、实际如何计算、图中有哪些定量差异以及最终认识。
```

技能指导写作和检查；读取数据、制作 DOCX/PPTX、绘图和渲染由当前环境的相应工具完成。没有指定工具或模板时，使用环境中可用的方案。两个技能互相独立，不要求安装私人项目中的其他技能。
