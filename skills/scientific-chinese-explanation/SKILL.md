# 中文科研报告写作

让读者知道研究对象是什么、每一步为何需要、具体怎样做、结果是什么，以及这些结果回答了什么问题。详细解释应增加认识，避免用重复结论、形容词和文件名撑长篇幅。

## 从本次问题组织报告

沿用用户给定的章节范围、受众和详细程度。先列出需要回答的实质问题，再为它们找到资料、方法、图表或文献依据。已有参考稿或人工修改稿时，学习其解释深度和段落组织，不搬用其他项目的事实。

常用讲述顺序为：研究对象与目的 → 资料及用途 → 方法与步骤关系 → 实际比较与最终选择 → 定量结果 → 科学认识和项目阶段。按问题取舍，不固定段落或章节数量。

对于“某个对象怎样得到”的章节，解释对象定义、输入资料、计算步骤、参数作用、结果形态及后续用途。对于真实的方法修改，说明原做法、遇到的问题、诊断依据、调整、比较和最后选择；没有发生的问题不编造为修复故事。

## 建立事实底稿

1. 读取用户指定的原始报告、方法说明、图件与数值表。描述已有实现时，核对实际执行的函数、参数和资料版本。
2. 对主要数字记录对象、时间、空间、单位、统计量、分母和来源。区分观测、背景产品、模型结果和教学算例。
3. 图上看起来存在的特征，优先用配套数据核实。按写作需要汇总已有结果，不自行改变模型或覆盖原始资料。
4. 多个版本先确认各自用途。当前方法、历史试验、已完成结果和后续计划分别使用准确名称。

底稿服务于核对，正文只保留读者理解研究需要的信息。技术追溯按需要放入资料索引或附录。

## 名词放回实际工作中解释

首次出现重要名词时，说明它指什么具体对象或功能，再把它放进相关步骤。不能用另一个抽象词或缩写代替解释。

每个重要步骤应使读者理解：

- 使用什么资料：来自哪里，对应什么位置、时刻和尺度。
- 做什么操作：搜索、筛选、投影、归一化、加权或优化具体作用于什么。
- 为什么需要：处理前一步留下的哪个实际问题。
- 得到什么：线、距离、浓度、概率、分类还是其他对象，单位是什么。
- 后面怎样使用：这一步的结果如何进入下一步，或者如何支持一个判断。

用连续自然段表达这些关系，不必每段机械填写五个标签。复杂方法可以展开多段，但每段都要推进解释。公式先用普通语言说明运算，再解释符号和单位；优先给真实数据例子，假设算例须明确标注。

## 用数值形成结果段落

先说明比较对象与共同条件，再给成对数值、差异幅度和对应解释。完整写明谁与谁比较、何时何地比较、百分比以什么为分母。通常每段两至四个关键数字即可支撑一个发现，其余同口径数据放表格。

保留与问题相关的空间、时间和组间差异，以及与总体趋势相反的结果。全域平均、局地极值和个例分别承担合适的解释作用。描述性比较使用描述性结论，不为增强语气临时制造显著性或因果断言。

不同定义的指标先分别命名，再比较。浓度与通量、状态与变化、训练拟合与留出预测、相对指数与概率，各按实际含义使用。

定量叙述的详细方法和示例见 [evidence-narration.md](references/evidence-narration.md)。

## 打开图件，解释图中增加的认识

每幅核心图需要回答：比较哪些对象，坐标和图形编码表示什么，哪里或何时最突出，具体幅度怎样，以及这张图为研究问题增加了什么认识。

- 热图交代横纵方向怎样读；地图交代范围、方向和图例；多面板图说明各面板关系。
- 区间按其实际定义命名，图中样本数量按真实统计单位解释。
- 不同色标不能仅凭颜色深浅直接比较；时间曲线的波动需要相应资料支持解释。
- 比较同一现象的图表可以相邻组织，避免让读者跨越多个章节自行拼接。
- 图名、正文、数值表及图中标注应指向同一个对象。

## 让文献支持具体命题

优先核对原始论文与权威资料。每篇引用对应具体定义、方法、结果或机制，放在所支持的句子附近。摘要不足以支持细节时继续查正文；取不到资料时缩小所写细节。

比较既有研究时，交代变量定义、时间空间范围和统计方法是否相同。分别说明可直接比较的量值、相似的格局以及文献支持的机制解释。只有实际完成相应比较，才写误差或独立验证结果。

## 自然、明确的中文

用真实对象和动作推动段落，先让读者认识对象，再使用必要术语。核心名称保持一致，避免为了语言变化而更换概念。

正文直接说明实际做法、已有结果和获得的认识。必要定义和数据性质在相应位置说清，不反复堆叠“不能、不可、尚未”等防御性句式，也不以大段内部审核说明代替分析。

删去程序性自述、空泛升华、无数值支持的夸大形容词，以及与研究问题无关的仓库、脚本和运行记录。保留影响结论的细节与相反证据。一个段落完成一项有内容的解释，避免把正文拆成零碎标签和待办清单。

## 完成交付

按用户指定格式交付完整正文或可编辑文件。报告以连续段落展开，同一逻辑用于PPT时可按页面问题组合图表；不把单个范例的页数、字号或研究参数固定为通用要求。

交付前核对数字与原表、公式与实际方法、图解与最终图件、引用与已核查原文。使用当前环境支持的文档工具检查实际排版，修复分页、图表、字体和编号问题，并保留原始成果。
