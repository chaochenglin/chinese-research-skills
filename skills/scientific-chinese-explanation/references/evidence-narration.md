# 把数字写成有解释的段落

## 先确定比较基础

整理研究对象、变量含义、单位、时间空间范围、样本或分母、权重、比较基准和来源。定义不同的量分别命名，不通过一个模糊标签合并。

## 组织主要发现

根据当前问题选用以下要素，不必机械列成标签：

1. 说明哪个对象呈现了什么变化。
2. 给出比较双方的数值和单位。
3. 说明绝对差；需要相对差时写清基准。
4. 用范围、分组或时序说明整体值对应的结构。
5. 指向支持这一发现的图表或原文。
6. 解释该差异回答了什么问题。

例如，在一个明确标作教学假设的例子中，两种方法在相同记录上的误差为0.20和0.16，可以写“第二种方法的误差比第一种低0.04，相对降低20%”。不能把这一例子的数值移入实际研究，也不由总体差异推断每个区域都改善。

## 选择有辨别力的对照

区域比较采用相同时间、尺度和统计量；时间比较交代起止日期与采样数量。给局地极值附上地点和时间，给全域概括附上覆盖范围。

“更稳定”要说明变化范围或相应统计量，“误差降低”要给参照方法，“具有某种季节性”要指出对应月份和数据变化。形容词后没有实数或图件证据时，继续补充内容或删去形容词。

## 结果与解释相接

先完成数据比较，再写科学解释。机制可能来自实际模型计算、现场证据或文献，应按来源选择“显示”“提示”“可能”等合适表述。科学准确性落实在对象、数字和定义中，避免用反复声明谨慎代替具体分析。
